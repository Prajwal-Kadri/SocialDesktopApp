# NITK Social Desktop App

A Java desktop application created for the NITK Social App project. The repository contains the NetBeans project, UI form, source code, and compiled build artifacts.

## Run locally

1. Open the project in Apache NetBeans.
2. Ensure a compatible JDK is configured.
3. Build and run the project from NetBeans.

The primary source is under `src/`; `build/` and `dist/` contain generated artifacts.

## Tech

Java · Swing · Apache NetBeans
